Actividad 4. Verificar si una palabra pertenece al conjunto de palabras del juego

Descripción de la actividad
En una sopa de letras real, el jugador debe buscar palabras pertenecientes a un conjunto
específico de palabras ocultas dentro del tablero.
En esta actividad se trabajará con un pequeño conjunto de palabras definidas en el
programa. Estas palabras representarán las que existen dentro de la sopa de letras.
El programa debe pedir al usuario una palabra e indicar si esa palabra pertenece o no al
conjunto de palabras del juego.
Para representar las palabras del juego, el programa debe definir cinco constantes, cada
una con una palabra distinta.
No se permite usar listas. Cada palabra debe guardarse en una constante independiente.
El objetivo de esta actividad es practicar la comparación de cadenas, el uso de constantes y
la repetición de intentos mediante estructuras iterativas.

Constantes del programa
- una constante para la palabra PYTHON
- una constante para la palabra CICLO
- una constante para la palabra CODIGO
- una constante para la palabra VARIABLE
- una constante para la palabra PROGRAMA

Datos de entrada
El programa debe pedir:
- una palabra

Después de mostrar el resultado, debe preguntarle al usuario si desea intentar con otra palabra.

Qué debe hacer el programa
1. Definir cinco constantes que representen las palabras del juego.
2. Pedir al usuario que ingrese una palabra.
3. Comparar la palabra ingresada con cada una de las constantes.
4. Determinar si la palabra pertenece al conjunto de palabras del juego.
5. Mostrar uno de los siguientes resultados: la palabra pertenece a la sopa de letras o no pertenece
a la sopa de letras.
6. Preguntar al usuario si desea intentarlo nuevamente.
7. Repetir el proceso hasta que el usuario indique que desea terminar.

Ejemplo orientador 1
- Palabras definidas en el programa:
    - PYTHON
    - CICLO
    - CODIGO
    - VARIABLE
    - PROGRAMA

Entrada del usuario:
- palabra: PYTHON
Salida esperada:
- Resultado: la palabra pertenece a la sopa de letras.
