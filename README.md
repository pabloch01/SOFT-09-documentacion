# SOFT-09-documentacion
El presente repositorio contiene los siguientes elementos de acuerdo con las indicaciones de la práctica 2:

1. Portada con datos personales (nombre, curso, docente).
2. Enlace del repositorio creado, el repositorio debe contener mínimo:
- 2 ramas.
- Un archivo .md.
- Un documento o archivo.
- 3 commits.
3. Conclusión general sobre lo aprendido y una referencia a la aplicabilidad
profesional.

Para efectos de la práctica, se trabajará bajo el contexto de una versión inicial del proyecto “Sopa de Letras”. Cada actividad corresponde a un programa independiente, enfocado en el análisis de datos de entrada y la toma de decisiones.
